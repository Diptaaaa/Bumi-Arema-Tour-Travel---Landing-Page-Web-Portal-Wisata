Website responsif modern agen perjalanan wisata Jawa Timur berbasis di Kota Malang, menyajikan paket perjalanan menuju destinasi alam kelas dunia (**Gunung Bromo**, **Air Terjun Tumpak Sewu**, dan **Kawah Ijen**).

Proyek ini dikembangkan sebagai portofolio resmi untuk kursus **"HTML and CSS in depth"** dalam program **Meta Front-End Developer Professional Certificate** oleh **Meta** di **Coursera**.

---

## 🌟 Fitur & Keunggulan Utama

- **🏛️ Arsitektur Semantic HTML5**: Menggunakan elemen semantik standar industri (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, dll.) untuk aksesibilitas (a11y) dan keramahan SEO.
- **📐 Modern CSS Grid & Flexbox**: Tata letak kartu destinasi 3-kolom yang adaptif dan rapi pada desktop serta otomatis bertumpuk (stack) pada resolusi layar mobile.
- **🎯 Promotional Hero Banner**: Banner promosi diskon liburan 25% dengan tombol call-to-action (CTA) interaktif dan overlay kontras tinggi.
- **📱 100% Fully Responsive**: Didesain dengan pendekatan *mobile-first*, tampak proporsional di berbagai perangkat (smartphone, tablet, laptop, dan monitor desktop).
- **✨ Tipografi & Visual Menarik**: Mengintegrasikan tipografi Google Fonts (*Plus Jakarta Sans*), micro-interaction hover efek kartu, dan palet warna modern bertema petualangan alam.
- **🧭 Navigasi Lengkap**: Header navigasi horizontal dengan 4 menu utama (*Home*, *Destinasi Wisata*, *Paket Tour*, *Kontak Kami*) serta footer informatif 2-kolom.

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/Diptaaaa/Bumi-Arema-Tour-Travel---Landing-Page-Web-Portal-Wisata.git
   ```
